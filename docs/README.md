# Documentation

This folder is **not** part of any submitted PDF. Two kinds of file live here.

**Working notes** are the durable record of grading, citations, and open work.
They are long, dated, and meant to be appended, not rewritten from scratch.

**The guide** (`guide/`) is a map of the whole repository: what each file is,
what it is for, and which other file is the source of truth. Start there if
the question is "what is this?".

| File | Kind | What it is |
| --- | --- | --- |
| [`guide/README.md`](guide/README.md) | Guide | Index of the encyclopedia. Start here. |
| [`ASSESSMENT.md`](ASSESSMENT.md) | Working note | Criterion-by-criterion grading record (Finnish 1-5). Two current grades: the full draft and the supervisor skeleton are not interchangeable. |
| [`TODO.md`](TODO.md) | Working note | Phase checklist, dataset status, and open items **O** to **S**. |
| [`LITERATURE_NOTES.md`](LITERATURE_NOTES.md) | Working note | Literature sweeps and candidate sources. |
| [`Sources_evidence.md`](Sources_evidence.md) | Working note | Per-bibliography-entry citation audit (metadata, claim, supporting passage). |
| [`citation.md`](citation.md) | Working note | How to add a bibliography entry and where metadata comes from. |
| [`CHAPTER_READABILITY.md`](CHAPTER_READABILITY.md) | Generated | Per-chapter Flesch table for `Thesis_v3.tex`. Regenerated by `.chapter_readability.py`. How the score is computed is in that file. |
| `review/` | Local only | Commented PDFs a reviewer returns. Gitignored. Read by `pdfannots.py`. Create the folder locally if it is missing. |

Related files that are **not** in this folder, on purpose:

| [`../source_audit_v3.pdf`](../source_audit_v3.pdf) | Same audit scoped to `Thesis_v3`. |
